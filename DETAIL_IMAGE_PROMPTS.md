# MetaX.Academy — Detail-Page Hero Image Prompts (copy-paste ready)

Every **detail landing page** (`detail.html?type=…&id=…`) now shows a **cinematic, slow-panning full-bleed background image** behind an animated branded gradient. The image sits under a dark readability veil, so the **lower third of every image should be darker/quieter** (the title and pills overlay there).

## How to use this file
1. Pick the row for the file you want.
2. **Copy the entire prompt cell verbatim** into your image generator (Midjourney, nano-banana, Seedream, Flux, DALL·E, etc.). Each prompt is **fully self-contained** — the shared style DNA is already baked into every single prompt, so you do **not** need to add anything.
3. Save the result to the exact **file path** shown, at **1920 × 1080 px (16:9), JPG, under ~450 KB**.
4. Reload the detail page — the hero background fills in automatically.

> The detail hero reuses the **same file** as the card thumbnail, so generating the file below also fills the card. If you'd rather have a *separate, more cinematic* hero, save it under the same path anyway (the card and hero share it by design).
