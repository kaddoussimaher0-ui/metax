# MetaX.Academy — News Image Prompts (copy-paste ready)

These images fill the placeholders on the **Academy News** hub (`news.html`) and each **article** page (`article.html?id=…`). The same file is used for a post's card thumbnail **and** its article hero — generate it once and both fill in.

## How to use
1. Find the row for the file you want.
2. **Copy the whole prompt cell verbatim** into any image generator (Midjourney, nano-banana, Seedream, Flux, DALL·E, etc.). Every prompt is **fully self-contained** — the shared style DNA is already included, so paste it as-is with **no modifications**.
3. Save to the exact **file path** shown.
4. Reload the page — the placeholder fades into the image automatically.

**Output spec (all files):**
- News hero (`news-hero.jpg`): **1920 × 720 px** (wide banner, ~16:6), JPG, < 400 KB.
- Card / article images (`news-01.jpg` … `news-09.jpg`): **1600 × 900 px** (16:9), JPG, < 350 KB.
- sRGB · no embedded text · keep a slightly darker lower third.

**Shared style DNA (already baked into every prompt below):**
> ultra-premium futuristic editorial digital art, deep space-black background #05060f, luminous volumetric gradients, glowing thin line-work, subtle particle field and starfield, cinematic rim lighting, high detail, 8k, no text, no watermark, no logos, no human faces, 16:9.
