# MetaX.Academy — Image Prompt Index

Every card in the site has an **image placeholder** with a fixed **image index**.
Generate each image and save it to `img/` using the **exact filename** listed below.
Until a file exists, the site shows an animated shimmer placeholder labelled with its index — the moment the real file is present at that path, it fades in automatically (no code change needed).

**Shared style DNA (put at the end of every prompt for a consistent set):**
> Ultra-premium futuristic tech aesthetic, dark cosmic navy background (#05060f), neon aurora gradients (violet #7c4dff → indigo #4d63ff → cyan #22d3ee → magenta #ff4dcd), soft volumetric glow, glassmorphism, subtle star field and thin grid lines, cinematic depth of field, 3D render / high-end editorial illustration, no text, no watermark, 16:9.

**Recommended output:** 1600×900 px (16:9), JPG, < 400 KB each. Keep the focal subject slightly off-centre and leave the lower third darker (the UI overlays a gradient there).
