# Credentialing Alignment Map

This file reconciles earlier generated credentialing language with the governing names and rules in MX-005 of [THE METAX CORPUS](https://www.genspark.ai/api/files/s/nTW7w8tC).

## Naming precedence

MX-005 names the four credential tracks as follows:

1. **Series Practitioner**
2. **Professional Operator**
3. **Master-Fellow**
4. **MetaX Contributor**

These names prevail over any alternate shorthand or local variant.

## Mapping table

| Earlier generated element | MX-005 counterpart | Disposition |
|---|---|---|
| badge / completion marker | pre-track completion evidence | retained only as non-credential completion signalling |
| Series Practitioner | Series Practitioner | exact match |
| Professional Operator | Professional Operator | exact match |
| Master-Fellow | Master-Fellow | exact match |
| contributor-readiness / governance contribution path | MetaX Contributor | use only as preparation language; award naming must be MetaX Contributor |
| D1-D5 rubric | MX-005 §5.2 | exact match; frozen scheme |
| P0-P3 proof ladder | MX-005 §5.3 | compatible operational shorthand |

## Implementation rule

Any reviewer handbook, rubric pack, verifier page, learner dossier, academy directory, or badge taxonomy generated after this file must use the MX-005 names exactly. If an older file uses a competing label, preserve the history but annotate it as superseded terminology.

## Renewal reminder

Practitioner does not expire. Professional renews at 36 months. Master-Fellow does not expire but remains under standing review. MetaX Contributor renews at 12 months. Source: [THE METAX CORPUS, MX-005 §§5.1 and 5.9](https://www.genspark.ai/api/files/s/nTW7w8tC).
