# MetaX.Academy — Hero-Section Background Prompts (copy-paste ready)

Every page now has a **full-bleed, body-width hero band** between the navbar and
the content, with a slow-panning background image (`.hero-bg`, wired via the CSS
var `--hero-img`) sitting under animated aurora/grid/particle layers and a dark
readability veil.

## How to use
1. Find the row for the page you want.
2. **Copy the whole prompt cell verbatim** into any image generator
   (Midjourney, nano-banana, Seedream, Flux, DALL·E, etc.). Every prompt is
   **fully self-contained** — the shared style DNA is already baked in.
3. Save to the exact **file path** shown.
4. Reload the page — the hero background fades in automatically (no code change).

**Output spec (all hero files):**
- **2400 × 1350 px (16:9)**, JPG, < 500 KB, sRGB.
- **Dark, low-contrast centre** and **quieter lower third** — the H1, deck and
  buttons overlay there. Push detail/energy to the edges and top.
- No text, no watermark, no logos, no human faces as focal subjects.

**Shared style DNA (already included in every prompt below):**
> ultra-premium futuristic editorial digital art, deep space-black background
> #05060f, luminous volumetric aurora gradients (violet #7c4dff, indigo #4d63ff,
> cyan #22d3ee, with restrained magenta #ff4dcd, gold #ffcb6b, emerald #3ee6b0),
> glowing thin line-work, subtle drifting grid and starfield, cinematic rim
> lighting, high detail, 8k, no text, no watermark, no logos, no human faces,
> dark low-contrast centre with a quiet darker lower third for overlay, 16:9.
