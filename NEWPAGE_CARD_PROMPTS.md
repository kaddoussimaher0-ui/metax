# MetaX.Academy — New-Page Card Art Prompts (copy-paste ready)

Card art for the mega-menu pages added in v2026.08: **The Meta-X Ascent**
(rungs S38–S47), **BCIA Gateway** (S48–S50), **Academies** requirement groups
(11), and **Library** standards (6).

Each card renders an indexed shimmer placeholder until its file exists at
`img/cards/<index>.jpg` (lower-cased). Example: index `AS-38` →
`img/cards/as-38.jpg`. The image fades in on load — no code change needed.

## How to use
1. Find the row for the card you want.
2. **Copy the whole prompt cell verbatim** — the shared style DNA is baked in.
3. Save to the exact **file path** shown.
4. Reload the page — the placeholder hydrates automatically.

**Output spec (all card files):**
- **1200 × 800 px (3:2)**, JPG, < 350 KB, sRGB.
- One clear centred motif; no text, no watermark, no logos, no human faces.

**Shared style DNA (already included in every prompt below):**
> ultra-premium futuristic editorial digital art, deep space-black background
> #05060f, luminous volumetric aurora gradients, glowing thin line-work, subtle
> particle field and starfield, cinematic rim lighting, high detail, 8k, no
> text, no watermark, no logos, no human faces, single centred motif, 3:2.
